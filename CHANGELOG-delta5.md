# delta5
- Kernel 1.5.0: K.direct (exact face-level direct editing on analytic bodies), K.faceLoops, 51 new kernel tests.
- App: Direct+ tools, 5 guided Direct editing lessons.
- SubD tools now work on any solid (Form, extrude, boolean, import): a selected solid is turned into a SubD cage on the spot (remeshed when it has faces with holes).
- New Convert tools: Solid to SubD, NURBS to SubD (fitted cage). With SubD > To solid / To NURBS this links solid, SubD and NURBS both ways.
- 3 guided Cross-model lessons.
