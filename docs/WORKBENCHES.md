# Aakar 8.6 – Part, Assembly and Sheet metal workbenches

Three ribbon tabs next to **Model**. Everything is parametric: each step is a feature in the history (double-click to edit, suppress, roll back, undo) and is saved inside the `.aakar.json` file. Each tab has an **Examples** button.

## Part
**Hole wizard** (simple / counterbore / countersink / tapped), **Standard parts** (ISO hex bolt, socket screw, nut, washer, 6xxx bearing, dowel pin, M3 – M24), **Properties** (name, number, revision, material, custom properties), **Mass properties** (volume, area, mass, centre of gravity, inertia) and a printable data sheet.

## Assembly
Component list (show / hide, **lock**, material, move, isolate, delete), mates (coincident, concentric, distance, angle, **parallel**, **perpendicular**, gear), component **pattern**, exploded view, **interference check**, **BOM & mass** (CSV / HTML).

## Sheet metal
Base flange from a closed sketch, **Edge flange**, **Hem**, **Jog**, **Cut-out**, **Flat pattern** with bend table (bend allowance / deduction), blank size and weight, **DXF / SVG** export and **Unfold 3D**.

See also: [Part+](PART_PLUS.md) for the advanced solid tools.
