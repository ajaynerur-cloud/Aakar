# Aakar 8.6 – Part, Assembly and Sheet metal workbenches

Three ribbon tabs next to **Model**. Everything is parametric (history features, editable, saved in `.aakar.json`). Each tab has an **Examples** button.

- **Part:** Hole wizard (simple / counterbore / countersink / tapped), standard parts (ISO bolts, nuts, washers, bearings, pins), properties and material, mass properties (volume, area, mass, centre of gravity, inertia), data sheet.
- **Assembly:** component list (show / hide, lock, material, move, isolate, delete), mates (coincident, concentric, distance, angle, parallel, perpendicular, gear), component pattern, exploded view, interference check, BOM & mass (CSV / HTML).
- **Sheet metal:** base flange, edge flange, hem, jog, cut-out, flat pattern with bend table, DXF / SVG export, unfold in 3D.

See also [Part+](PART_PLUS.md) and [NURBS+](NURBS_PLUS.md).
