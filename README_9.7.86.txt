Aakar 9.7.86 - start page

Copy into your repo (Aakar-main), replacing files of the same name:
  app/index.html        the app (single file)
  app/tutorials/        3 short videos + posters (must sit next to index.html)
  main.js, preload.js   desktop only: workspace folder (Settings > Workspace folder on the start page)

Android (Capacitor): copy app/index.html and app/tutorials/ into your www folder, then cap sync.
Web / tablet: nothing else needed; the workspace folder option is desktop-only.
